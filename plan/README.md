# AGCL — American Gold Contract for Liberty

This repository contains the canonical control system and implementation plan for the AGCL.

## Structure

### /controls
Binding system constraints (00A–00J)

### /plan
Execution framework (Points 01–10)

## Design Model

- Controls = Rules (non-negotiable)
- Plan = Execution (adaptable within rules)

## Key Principle

Government must operate under:
- time limits
- property rights
- exit mechanisms
- automatic enforcement

## Objective

Replace:
- perpetual taxation
- debt-based governance
- opaque spending

With:
- ownership
- transparency
- finite authority
